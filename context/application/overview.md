# Application Context Scope

The profile selects application-specific guidance. Local facts live under [compliance-hub](compliance-hub/INDEX.md); reusable architecture, UI, security, data, and delivery standards live in their own packs.

Use source, schemas, tests, deployment configuration, and runtime evidence to verify implementation. Older root documentation remains useful but may describe an earlier version. A discrepancy should cite both sources and the current code path; do not silently amend an unrelated document.

No application migration, security remediation, or release is authorized by the presence of a pattern. Changes follow the current request and its acceptance criteria.
