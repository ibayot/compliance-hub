# Application Foundations

Consult only the principles relevant to the routed task. Concrete element behavior belongs in the design-system patterns; technical decisions belong in architecture and technology context.

## Principles

- [UI Consistency Principles](ui-principles.md) — UI design, component selection, consistency review.
- [Accessibility Principles](accessibility.md) — interactive UI, accessibility review, visual consistency.
- [Content and Terminology Guidelines](content-guidelines.md) — labels, messages, terminology, localization.
- [Engineering principles](engineering-principles.md) — boundaries, maintainability, source evidence, and proportional verification.

## Usage

Read the [active application profile](../application/PROFILE.md) first. These baselines guide new or touched work; existing behavior must be inspected before assessing conformance. A principle does not establish a new framework, visual theme, or mandatory global store.

Link an observed discrepancy to a specific rule and code location. Separate a proposed standard, an observed implementation, and a verified finding in audit output.
