# Content Patterns

Use consistent terminology and truthful task-level messages. Match the application's glossary and locale policy; do not expose implementation details or private data.

- [Helper Text Pattern](helper-text-pattern.md) — help text, input instructions, format guidance.
- [Validation Message Pattern](validation-message-pattern.md) — validation wording, required error, constraint error.
- [Confirmation and Outcome Message Pattern](confirmation-message-pattern.md) — success message, confirm wording, completion text.
- [Error Message Pattern](error-message-pattern.md) — error wording, safe failure message, support code.
- [Date, Time, and Number Format Pattern](date-and-number-format-pattern.md) — date formatting, timezone display, currency, number format.
- [Status Language Pattern](status-language-pattern.md) — status wording, workflow label, state text.
