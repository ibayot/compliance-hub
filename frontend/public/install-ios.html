Install FO2 iCare on iPhone

  1. Download the FO2 iCare installation profile, then install it from iPhone Settings under VPN & Device Management.
  2. Open Settings → General → About → Certificate Trust Settings and enable full trust for the internal root certificate included with the FO2 iCare profile.
  3. Open the new FO2 iCare Home Screen icon, sign in, and choose Browser alerts → Enable from the bell menu.

iOS requires this one-time full-trust step for a manually installed root certificate. Notification sounds and badges remain controlled by iOS settings.
